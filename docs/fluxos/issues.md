## Por que a mudança

Até 29/07/2026 o backlog existia em dois lugares: este arquivo e as GitHub Issues.
As duas versões divergiram — a Issue 2 (SEO) estava concluída aqui e aberta no
GitHub, a Issue 1 (imagens) estava marcada como feita aqui quando na verdade não
tinha sido, e havia issues no GitHub referenciando `index.html` e `script.js`,
arquivos que não existem desde a migração para o Astro.

Duas fontes de verdade para a mesma informação sempre divergem. A escolha foi
ficar com as GitHub Issues, porque commits se vinculam a elas automaticamente e o
histórico fica visível para quem olha o repositório.
